How A-Tuls Works

Index → Package → API → Sign Up → Dashboard

Review the available tools and packages before creating your account.

Contact Admin

Message the A-Tuls Admin on WhatsApp and choose your package.

03💳

Complete Payment

The Admin will provide the payment instructions and package rules.

04🔑

Receive API Code

Create Your Account

Use the correct API code during registration when a package requires it.

06🚀
